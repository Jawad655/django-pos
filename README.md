# 🍽️ Django Restaurant POS & Inventory System

Ek complete aur professional Point of Sale system jo restaurants, cafes aur hotels ke liye banaya gaya hai. Django + Python me bana hua hai.

## ✨ Key Features

- **POS Billing**: Fast table-wise ordering, KOT print, Final Bill
- **Menu Management**: Categories, Items, Price, Image add/edit/delete
- **Inventory & Stock**: Stock in/out, low stock alerts, wastage track
- **Sales Reports**: Daily, Monthly, Item-wise sale reports + Profit calculation  
- **User Roles**: Admin, Manager, Cashier ke alag alag login
- **Customer Management**: Customer history aur pending bills
- **Responsive**: Mobile, Tablet aur Desktop sab pe chalta hai

## 🛠️ Tech Stack
- **Backend**: Python 3.10, Django 4.2
- **Database**: SQLite 
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Other**: PDF Bill Generation
